# Naya article kaise daalein

1. GitHub par is repo mein `_posts` folder kholiye → **Add file → Create new file**.
2. File ka naam: `YYYY-MM-DD-chhota-naam.md` (jaise `2026-11-05-zoho-crm-benefits.md`).
3. Neeche wala template copy karke bhariye, phir **Commit changes** dabaiye.
4. 1–2 minute mein article https://hmitechnology.co.in/articles/ par aa jayega.

```
---
title: "Article ka headline"
summary: "1–2 line ka chhota summary (list aur Google mein dikhega)"
icon: "💡"                     # photo na ho to card par yeh emoji dikhega
cover: "/images/articles/photo.jpg"   # optional: images/articles mein photo upload karke
linkedin: "https://www.linkedin.com/pulse/..."   # optional: LinkedIn post ka link
tags: [ERPNext, BusinessAutomation]
---

Pehla paragraph yahan.

## Sub-heading

- **Bold point:** detail
- Doosra point

[Contact us](https://hmitechnology.co.in/#contact)
```

Formatting: khaali line = naya paragraph · `## ` = heading · `- ` = bullet · `**text**` = bold.
